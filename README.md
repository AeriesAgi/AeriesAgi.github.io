# Ashveer Ramlukan — professional profile

A dependency-free static personal/professional site focused on:

- Founder profile and Culltron positioning
- Status-labelled Culltron systems
- Public engineering proof
- MSc Financial Engineering and prior IT qualifications
- Public professional contact routes only

## Privacy and claims boundary

The page intentionally excludes residential details, phone numbers, family information, banking/financial records, support disputes, client amounts, customer credentials, private hostnames and unpublished personal material.

Programme access is described as access or verification, not as endorsement. Product maturity is labelled explicitly. Synthetic demos are not represented as live deployments.

## Run locally

```bash
python3 -m http.server 8080
```

Open `http://localhost:8080`.

## Deployment note

The target GitHub Pages repository currently contains a `CNAME` for `teflandbeyond.me`. This site does not alter that file. Confirm the intended domain before merging or changing DNS.
